# Hospital Management System – Project Statement

## 1. Problem Statement

Hospitals manage a large amount of information related to patients, doctors, appointments, medicines, rooms, payments, staff, emergency cases, blood banks, and other services.

Managing these records manually can be time-consuming and can make it difficult to add, view, update, and delete information efficiently.

The **Hospital Management System** is developed as a simple Python-based application to organize different types of hospital records through a single menu-driven system. The project divides hospital activities into separate modules and provides basic CRUD operations for managing records.

## 2. Scope of the Project

The project focuses on the basic management of hospital-related information.

The system covers:

- Patient records
- Doctor records
- Appointment records
- Blood bank records
- Emergency records
- Medicine stock
- Room records
- Payment records
- Insurance records
- Security camera records
- Canteen records
- Cleaning staff records
- Guard records
- Intern records
- Death records

The project is designed mainly for educational and demonstration purposes. The current version stores information temporarily using Python lists.

## 3. Target Users

The project can be used by:

- Students learning Python programming
- Beginners learning CRUD operations
- Students learning modular programming
- Students developing academic projects
- Teachers and project evaluators for demonstration
- Beginners interested in hospital management system concepts

The system can be further developed for actual hospital staff by adding authentication, database connectivity, and proper user roles.

## 4. High-Level Features

### 4.1 Main Dashboard

Provides a central menu to access different hospital management modules.

### 4.2 Patient Management

Allows users to add, view, update, and delete patient information.

### 4.3 Doctor Management

Allows management of doctor details such as ID, name, specialization, experience, and other basic information.

### 4.4 Appointment Management

Allows users to manage basic appointment information between patients and doctors.

### 4.5 Blood Bank Management

Provides basic management of blood group and blood bank information.

### 4.6 Emergency Management

Allows users to record and manage emergency case information.

### 4.7 Medicine Stock Management

Allows management of medicine names, quantities, prices, and related information.

### 4.8 Room Management

Provides basic management of hospital room information and room allocation.

### 4.9 Payment Management

Allows users to maintain basic payment records.

### 4.10 Insurance Management

Provides basic management of patient insurance information.

### 4.11 Staff and Support Management

Includes modules for:

- Guards
- Cleaning Staff
- Interns
- Security Cameras
- Canteen

### 4.12 Death Record Management

Provides a separate module for maintaining basic death records.

### 4.13 CRUD Operations

The project demonstrates the four basic data management operations:

- **Create / Insert**
- **Read / View**
- **Update**
- **Delete**

## 5. Project Goal

The main goal of this project is to demonstrate how basic Python programming concepts can be combined to create a modular and menu-driven **Hospital Management System**.

The project also provides a foundation that can later be extended with a database, graphical interface, authentication, and other advanced features.
